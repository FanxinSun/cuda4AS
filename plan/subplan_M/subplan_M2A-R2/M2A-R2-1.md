## Semantic validation detail

Capture the actual Homebrew executable and reported version, not merely a PATH
lookup or the manifest's intended_identity field. The declared >=18,<24 range
does not mean every major is qualified. Unexpected identity/arguments demand
a scoped decision, not automatic acceptance because a version is numerically
inside the range. No compiler installation is permitted.

Location normalization follows serialized insertion order, including declaration
loc, range endpoints and nested spelling/expansion locations. Recover elided
filename/line state only from valid preceding state; resolve relative paths
against recorded capture cwd. Check byte offset and line/column consistency
against the identified file. Preserve exact, de-elided and inherited provenance.

Builtins bind referenced declaration IDs to canonical VarDecls with direct
CUDADeviceAttr, supported names, pinned const dim3 type and verified facade
path/hash/anchor. device_builtin is ignored/non-AST; inventing an attribute child
to satisfy the importer is forbidden. Unsupported declaration shadows or forged
reference records must reject.

Type semantics come from supported Clang type representations, not fabricated
type.addressSpace/address_space fields. Kernel identity derives from real direct
attributes and declarations, not old attrs/isCUDAKernel shortcuts. Expressions,
loads/stores and control flow must correspond to compiler output. Unsupported
nodes/types/casts/address-space forms fail before Metal generation.

## Tests and completion

Test wrong source/compiler signature, malformed/empty/truncated JSON, missing
initial location state, wrong cwd/file/offset, reordered or conflicting location
data, forged builtin IDs/anchors, unsupported type and illegal ABI mapping.
Retain real capture independently of derived IR, including a failed capture.

Completion requires either the full verified real import or a complete stage
failure record. A missing compiler is NOT_RUN, not a passed synthetic fixture.
Only a verified real import permits the native pipeline's dependent stages.
Any corrective code change beyond the approved attempt is held for new scope.
