# M2A-R2-3 — One bounded native AOT attempt

Parent step: M2A-R2-3 in [M2A-R2](../M2A-R2.md).
State: PLANNED_NOT_AUTHORIZED. The user operates the Mac only after a separately
approved and actually delivered package; this document is not a launch request.

## Fixed boundaries

Retain no network/install/update/sudo, no OS/SDK changes, no CPU fallback and no
runtime compilation. Use the accepted Mac inventory and package, at least 5 GiB
free space, at most four parallel jobs, 20 GiB added disk and 30 minutes.
Preflight must record what it actually observes, not copy a historical report.

in a helper or in error recovery. M2A-R2-1's live tasks are performed at -3-1,
not in a separate run before the delivered package exists.

## Build and launch evidence

Capture exact argv, cwd, environment identity, duration, stdout/stderr and exit
for each stage. File presence alone is not success: verify nonempty expected
outputs and binding to the current inputs. Record generated MSL separately from
unchanged source and ensure it derives from verified compiler-semantic IR.

Single-TU linking here does not satisfy M2B's real cross-TU gate. Native host
linking and device image production are separate. The AOT manifest binds entry,
argument order/types/layout/address-space lowering, target and image digest;
wrong binding must reject before dispatch.

The runtime must record selected Metal device identity and successful completion
of actual work. cpu_fallback=false is a constraint and declaration, not launch
proof. No device identity or output can be synthesized after an earlier failure.
Metal pipeline creation is recorded, but no source compilation at runtime.

## Output and failure handling

Preserve the enrolled input/shape and expected vector_add bytes. The baseline
expected output is 4194304 bytes with its immutable corpus hash; obtain exact
source/reference hashes from the enrolled records, not a freshly computed
candidate golden. Preserve raw output even on mismatch.

A native output mismatch is a failure, not permission to adjust epsilon.
Stage failure, environment skip and unexecuted downstream work remain distinct.
Timeout/resource exhaustion must preserve logs and classify the attempt
truthfully; never kill unrelated user processes or erase previous results.

Use uniquely named output directories and collect only the intended run's
files. Include failure diagnostics and complete manifests; avoid user secrets
or broad system dumps. The archive itself is untrusted on return until -4
validates its member types/paths and recorded identities.

## Completion

Return the unchanged archive and digest with complete reached/unreached stage
findings. A complete negative return is a legitimate attempt outcome. No automatic
repair, environment upgrade or additional run follows. Independent manager-side
assessment remains necessary before any positive compatibility statement.
