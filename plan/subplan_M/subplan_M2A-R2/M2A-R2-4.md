## Safety and integrity detail

Inspect before extracting. Bound compressed/uncompressed bytes, file count and
path lengths under the approved resource envelope. Refuse symbolic/hard links,
devices/FIFOs, duplicate normalized paths and destination escape. No member may
overwrite a trusted analyzer or project file. Retain an unsafe original for
diagnosis without executing or trusting its content.

Require manifest completeness, not merely validation of listed members. Bind
against the package's immutable recorded member hashes, not files in a newer
checkout. Verify inventory and case IDs, source/compiler/facade schema versions
and exact source/reference identities. An archive digest alone does not establish
correctness of the contents.

## Classification detail

PASS_GPU needs the entire applicable stage chain, real device/launch evidence
and independently correct output. A runner self-report, successful preflight,
compiled metallib or cpu_fallback=false alone is insufficient.

Stage failure versus case failure follows the selected versioned result contract.
Do not retroactively reinterpret M1's NOT_RUN cases as FAIL or rewrite M2A-0's
recorded FAIL. Preserve legacy raw UNSUPPORTED/PASS_CPU_EXPLICIT labels when
reading old records; map unsupported to the current planning view explicitly
and keep CPU results outside Native AOT GPU pass counts.

Malformed/untrusted returns produce an analysis rejection/inconclusive record,
not an invented native outcome. Missing evidence stays missing. Report every
positive, negative, failed and inconclusive check, including discrepancies
between runner classification and derived classification.

## Regression and acceptance

Test unsafe/duplicate/extra/missing members, stale package hashes, wrong inventory,
truncated output, wrong stage order, success after failed dependency, missing
device identity, false PASS_GPU, incompatible schema and corrupted reference.
A valid negative archive must analyze successfully as a negative result;
successful analysis itself is not a GPU pass.

Return archive identity, complete redacted analysis, supporting evidence paths,
validation results, limitations and the exact remaining decision. Report delivery
and manager assessment separately; queued feedback is not proof of acceptance.
